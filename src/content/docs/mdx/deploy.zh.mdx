落地方式可选，工作语义不应分叉。选择部署是风险与运维问题，不是“另一套 Agent 协议”。

<h2 id="modes">三种落地</h2>

- Managed OS：Kense 托管控制面，适合快速上线。
- BYOC：控制面跑在你的云账号与 VPC，满足数据本地化。
- Self-hosted：部署、安全与升级自管，对接现有平台工程。

<h2 id="plans">订阅如何展开</h2>

1. Free：1 个 Work 席位，完成本地第一次会话。
2. Builder：完整 Work，并接入按用量计费的 OS。
3. Team：共享、策略发布与流程自动化。
4. Enterprise：专属或自托管、SSO / SCIM、定制 SLA。

Work 与 OS 不分开售卖。只读协作者使用方案内含席位；付费席位是使用 Work 或管理 OS 流程与策略的成员。
