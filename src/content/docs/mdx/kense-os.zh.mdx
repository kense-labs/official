Kense OS 让智能体与工作流可恢复、可持久。控制面保存意图与策略；Operations / Flow 做耐久协调；Workload 经 Fleet、Runtime、Box 落到节点。Gateway 是唯一公网入口。

<h2 id="plane">控制面做什么</h2>

- 身份与授权（Identity · Grants）
- 期望状态与日记账（Operations · Flow）
- 发布、版本与组织记忆
- 观测：审计、追踪、回放

<h2 id="services">一等服务</h2>

AaaS、WaaS、FaaS 与 Durable Cell 共用同一套控制面。Agent、Workflow、Function 不是三套互不相认的产品，而是同一语义上的不同入口。

```
Gateway → Identity → Operations / Flow → Workloads → Box
```

<h2 id="when">何时使用 OS</h2>

需要跨会话一致性、exactly-once 调用、人工审批、定时器或团队发布时使用 OS。只在本机改一个文件，Work 就足够。
